# T2.6 — Interrupt & timing skeleton (NMI/IRQ, frame loop)
Phase: 2   Depends-on: T2.3, T2.4   Status: pending

## Context
Game feel lives here: NMI/IRQ cadence and the frame structure pace everything.
Spec: `cdoc/hardware-berzerk.md` §5 (interrupts) and §1 (clocks). The
scheduler must be deterministic — cycle-counted, never wall-clock — because
Phase 3/4 reproducibility depends on it.

## Entry criteria
- [ ] T2.3 done (validated Z80 core integrated).
- [ ] T2.4 done (memory subsystem).

## Task
`machine/src/scheduler.js`: run the CPU in cycle-budgeted slices; raise NMI
and IRQ at the documented scanline/timer positions; honor enable/disable
ports; expose `runFrame()` (advance exactly one video frame) and a vblank
callback (input script application point, frame hashing point). V256/scanline
counter readable per spec.

## Out of scope
Real input/video/sound behavior (other tasks). requestAnimationFrame pacing
(T2.9 — scheduler itself must stay wall-clock-free).

## Definition of done
- [ ] Unit test: cycles per frame matches spec-derived value exactly.
- [ ] Unit test: NMI/IRQ delivered at documented cadence over N simulated
      frames (count + position asserted), and suppressed when disabled.
- [ ] Determinism test: two runs of M frames from reset → identical CPU state
      and memory hash.
- [ ] `npm test` passes.

## Verification
```
cd machine && npm test
```
