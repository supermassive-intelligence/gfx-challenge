# T2.7 — Input ports + DIP switches
Phase: 2   Depends-on: T2.4   Status: pending

## Context
CPU-visible input: joystick/buttons/coin/start ports and DIP switch banks.
Spec: `cdoc/hardware-berzerk.md` §3 (IO map) and §6 (DIPs/field names).
Field names must match the MAME driver exactly — the input-script schema
(`cdoc/schemas/input-script.md`) resolves names on both platforms.

## Entry criteria
- [ ] T2.4 done (`npm test` passes).

## Task
`machine/src/input.js`: port state objects keyed by the documented
port/field names; reads return correct bit packing (active-low where spec
says so); DIP banks configurable at construction, defaulting to the spec's
factory settings; programmatic `setField(port, field, value)` API — this is
what both the keyboard shell (T2.9) and the input-script player (T3.1) call.

## Out of scope
Keyboard mapping/browser events (T2.9). Script replay (T3.1).

## Definition of done
- [ ] Unit tests: every documented field flips exactly its documented bit;
      active-low polarity verified; DIP defaults match spec §6.
- [ ] Unknown port/field names throw (typo guard — silent misses here cost
      hours later).
- [ ] `npm test` passes.

## Verification
```
cd machine && npm test
```
