## Task
`machine/src/memory.js`: read8/write8 (+16-bit helpers) dispatching over the
documented map. ROM regions load from user-supplied ROM files (path via env
or config; never committed). Writes to ROM ignored (or logged in debug mode).
Device windows (magicram, color RAM, IO-adjacent ranges) dispatch to handler
hooks — stub handlers for now, real devices arrive in T2.5–T2.8. Include the
read/write tap mechanism (callback on any access in a range) — this is the
future trace-capture hook (Phase 4), designing it in now is free.
