# T3.1 — Freeze input-script schema + JS recorder/player
Phase: 3   Depends-on: T2.9   Status: pending

## Context
Cross-platform deterministic input replay is the foundation of every
validation step from here on. Draft schema: `cdoc/schemas/input-script.md`
(resolve its open questions here, then mark FROZEN). MAME INP files cannot
replay outside MAME — this format is the substitute, consumed natively by the
JS machine and injected into MAME via Lua (T3.2).

## Entry criteria
- [ ] T2.9 done (playable machine; HUMAN-GATE passed).

## Task
1. Resolve schema open questions (initial-state convention: recommend cold
   boot from reset; frame-0 semantics; multi-port naming). Update the schema
   doc, mark FROZEN, log decisions in `cdoc/decisions.md`.
2. `machine/src/script-player.js`: applies input records at vblank of the
   specified frame via `setField`; asserts script field names against T2.7's
   known-field registry.
3. Recorder in the browser shell: play with keyboard, dump script JSONL.
4. Record the first scenario library into `traces/scripts/`: attract-only
   (zero-input baseline), coin+start+first-maze, shoot-robot, player-death,
   maze-transition, ~60s free play. (HUMAN-GATE: human plays these.)

## Out of scope
