# T3.4 — Golden-frame gate: JS machine matches MAME
Phase: 3   Depends-on: T3.2, T3.3   Status: done (Sudnya signed off scope 2026-06-16)

## Scope (ratified by Sudnya 2026-06-16)
Exact-match gate = VISIBLE rows only (VRAM 0x4000-0x5BFF + color 0x8000-0x87FF),
zero tolerance, deterministic window **frames 0-258**. Proven: visible-only
bit-exact 0-258 (first visible diff frame 259); full-VRAM bit-exact 0-241 (first
diff frame 242 is the off-screen byte 0x5DE3). Beyond 258 the divergence is the
benign V256 timing-entropy path (T5.1 ruling), validated BEHAVIORALLY in
Phase 5+, not by golden frames. THIS GATE'S JOB = boot/POST/integration/render
regression for Phase 9 (`npm run golden` asserts frames 0-258). Gameplay-routine
correctness is the Phase 7/8 per-routine trace bench, NOT this gate.

## Context
THE Phase 3 exit gate and the project's standing regression suite. MAME hash
streams become committed goldens; the JS machine must match frame-for-frame.
This is the only test that validates timing, interrupts, and feel — unit
tests cannot. After this gate passes, traces from the JS machine are trusted
(plan Phase 4 may begin) and this suite runs after every future change.

## Result (2026-06-16, DONE — Sudnya signed off scope)
Cold-reset, no-input `attract-only.jsonl` (3085 frames), MAME 0.288, frame-0
alignment offset = 0 (first fully-drawn frame is 173 on both sides).

- FULL VRAM+colorRAM (0x4000-0x5FFF + 0x8000-0x87FF): first divergence at
  **frame 242** -- exactly one byte, VRAM 0x5DE3, JS=0x00 vs MAME=0xFF. 0x5DE3
  is VRAM row 239, which is OFF-SCREEN (only rows 0-223 render).
- VISIBLE VRAM rows 0-223 only (0x4000-0x5BFF + 0x8000-0x87FF): first divergence
  at **frame 259** (visible 1-byte diff at row 53). Excluding off-screen scratch
  extends the bit-exact window from 242 to 259 (+17 frames) -- modest, not large.

So the bit-exact JS-vs-MAME window (visible rows) is frames 0-258. The break is
the input-independent timing/RNG drift in the attract demo (MAME is itself
deterministic run-to-run: 0/3085 diff across two cold boots), confined to moving-
object regions -- not a CPU/rendering bug. See cdoc/decisions.md (2026-06-16) for
the scope carve-out and deferred input-harness work. Tools added:
tools/replay_hash_visible.js, tools/mame/replay_hash_visible.lua.
