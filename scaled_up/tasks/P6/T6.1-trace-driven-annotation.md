## Context
Plan Phase 6: understand the program from traces alone (method must generalize
to source-less games). Walk the call graph bottom-up; infer each routine's
purpose from read/write addresses (cross-referenced with the hardware contract
+ entropy catalog), argument registers, and observed effects.

## Entry criteria
- [ ] T4.1 done (traces + call graph).
- [ ] T5.2 done (entropy sites known, so "random" reads aren't mis-annotated).

## Task
Produce annotated assembly + a RAM variable map (addr → name → meaning) for
every trace-reachable routine. Name routines by behavior, not guesswork.

## Out of scope
Porting (T9). Scoring vs Frenzy source (T6.2). Routines never seen in traces
(leave flagged, not invented).

## Definition of done
- [ ] Every trace-reachable routine has a name + contract (inputs/outputs/

- [ ] RAM variable map committed.
- [ ] HUMAN-GATE: Sudnya spot-reviews a sample of annotations vs traces.

## Result (awaiting-human)

Method: annotated trace-driven from scratch. Names/contracts derived ONLY from
observed behaviour (read/write sets x hardware-berzerk.md + entropy-berzerk.md,
arg registers, call-graph position). Published Berzerk/Frenzy source, seanriddle
asm, and oracle `labels.json` were NOT consulted (the decode-oracle `label` field
was explicitly ignored; only its instruction bytes were used).

Deliverables:
- `cdoc/annotated-asm-berzerk.md` — 83 routines, each with behaviour-derived
  name + contract (inputs/outputs/side-effects) + purpose + entropy flag +
  call-graph + disassembly listing.
- `cdoc/ram-map-berzerk.md` — RAM variable map (NVRAM 0x0800-0x0BFF word-pairs +
  the VRAM-low variable/stack band 0x4000-0x43FF), addr -> name -> meaning, each
  row tagged with its trace r/w counts and writer routines.
- `machine/tools/t61/` — the evidence-generators (incl. a Z80 disassembler
  validated 5286/5288 vs decode_oracle) + README to reproduce.

Routine count: 83 distinct entry PCs (incl. 3 ISR vectors 0x0066/0x26AB/0x0509);
8 are shared-tail secondary entry points (0x1505,0x1E78,0x1F94,0x22F1,0x29A3,
0x2A4A,0x2B3D,0x2BE4), reconciling toward the task's "~81". None invented;
gameplay-only routines are out of scope (attract never credits play — see
entropy-berzerk.md sec4).

Entropy cross-check: 8 routines flagged as entropy-touching, all consistent with
entropy-berzerk.md — FRAME_IRQ_DISPATCHER 0x26AB (V256 @0x26B4), MOVE_AND_DRAW_BOLT
0x1553 + DRAW_OBJECT 0x272D (port 0x4E bit7 collision flop, deterministic),
RANDOM 0x2678, and the seed/RANDOM consumers START_GAME 0x1685,
GENERATE_MAZE_AND_ROBOTS 0x2540, PLACE_ROBOT_RANDOM 0x25EB, COROUTINE_ENTER 0x1E59.
