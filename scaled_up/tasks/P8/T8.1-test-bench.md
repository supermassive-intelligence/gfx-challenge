## Result (awaiting-human)

Bench: `machine/tools/bench.js` (hermetic — imports only node builtins + the pure
`src/roms.js`; NO z80 core, NO Machine, verified by grep). Port registry:
`machine/ports/index.js` (entry_pc -> port fn); sample port:

Port contract: `port(ctx)` mutates `ctx.{regs,flags,mem,io}` in place; the bench
builds a mock memory from the case (ROM image if present + writable read-seeds) +
an IO FIFO, runs the port, and diffs regs_out + writes. See decisions.md
2026-06-18 for the stripped-quantities rationale (stack scaffolding, `sp`, `r`).

## Sign-off — independent verification (Cowork review, 2026-06-18)

Sudnya signed off after the following were reproduced independently (carved ROMs
from disassembler/oracle/berzerk_flat.bin), not taken on report:
- HERMETIC confirmed: `grep` of imports in bench.js + ports/*.js shows only
  node builtins + the pure `src/roms.js` (+ ports/index.js -> random.js). No z80
  core / Machine / scheduler / video / memory. (An earlier "forbidden import"
  grep hit was comment text — "must NOT model the Z80 stack" — not an import.)
- `node --test machine/tests/bench.test.js` -> 6/6 (pass/fail/stack-strip/throw/
  skip + RANDOM integration), reproduced.
- `node tools/bench.js traces/test-plans/*.jsonl` -> RANDOM 4 pass / 0 fail,
  396 skipped, exit 0, reproduced.
- PORT IS GENUINE (not rigged to echo): read ports/random.js — it computes
  (7*seed+0x3153)&0xFFFF from mock-memory, writes 0x435C, sets A=high byte,
  clobbers DE, and derives the flag byte from first principles (C/H from the add,
  N=0, Y/X from result high byte, S/Z/P preserved). Cross-checked against T7.1's
  independently LCG-verified records => end-to-end real. The bring-up DE-clobber
  catch confirms the bench discriminates.
- Policies ratified: stripping stack-scaffolding writes, `sp` (+2 from ret), and
  `r` is correct; everything else (incl. full flags byte + clobbered regs) must
  match. NOTED nuance for Phase 9: the stack-strip is a heuristic (contiguous
  block descending from sp+1, stop at first gap); safe while game data lives far
  from the live stack (true for current leaf routines), but a routine writing
  data adjacent to its stack frame could theoretically have a real write stripped
  (possible false-pass, never a false-fail) — revisit if data/stack interleave.
