# T1.2 — Coverage feedback loop (traces → disassembly)
Phase: 1   Depends-on: Phase 4 (trace capture), T1.1   Status: blocked

## Context
Static Z80 disassembly cannot resolve computed jumps and inline data. Once
Phase 4 produces execution traces, PCs observed executing confirm code;
regions never executed across the full scenario library get re-examined as
data/tables. See plan Phase 1 (`cdoc/z80-port-plan.md`).

## Entry criteria
- [ ] T1.1 done (`coverage_report.json` exists).
- [ ] Phase 4 heavyweight traces exist in `traces/` for the full scenario set.

## Task (to be detailed when unblocked)
Tool: ingest traces, mark executed PCs, re-emit disassembly with code/data
separation; diff against `coverage_report.json`.

## Definition of done
- [ ] Every traced PC lands on an instruction boundary in the listing
      (mismatch = decode or classification bug; test fails with the address).
- [ ] Report of never-executed regions reclassified or flagged.

## Verification
```
cd disassembler && python -m pytest
```
