# T1.1 — ROM byte-accounting audit in disassembler
Phase: 1   Depends-on: none   Status: done

## Context
The disassembler (`disassembler/`, Python + pytest, oracle data under
`disassembler/oracle/`) exists and validates instruction decode against
skoolkit/Tunstall oracles. What it may not yet prove: that *every byte* of the
ROM is accounted for — classified as instruction, operand, or data — with no
gaps and no overlaps. That accounting is the foundation for the Phase 4
coverage loop (T1.2).

## Entry criteria
- [ ] `cd disassembler && python -m pytest` passes on main.
- [ ] `disassembler/oracle/berzerk_flat.bin` present.

## Task
Add a byte-accounting check (new test or tool): walk the full ROM address
range and assert each byte belongs to exactly one classification
(code-opcode, code-operand, data). Emit `disassembler/coverage_report.json`
summarizing counts and listing unclassified/ambiguous regions. If the
disassembler has no explicit data classification yet, the report may list
"unknown" regions — the test then asserts no *overlap* and that unknown
regions are enumerated, not silently dropped.

## Out of scope
Resolving unknown regions (that is T1.2, needs Phase 4 traces). Changing
decode logic. Touching oracle files.

## Definition of done
- [ ] `coverage_report.json` generated; schema documented in the tool's docstring.
- [ ] New pytest asserts: no byte double-classified; no byte missing from report.
- [ ] Full suite still passes.

## Verification
```
cd disassembler && python -m pytest
```

## Result (2026-06-10)
- Tool: `disassembler/byte_accounting.py` (schema in module docstring). Classifies
  every byte of the 6 populated ROM regions (12288 bytes) from the frozen
  decode_oracle: opcode 5288, operand 3433, unknown 3567 across 161 regions,
  0 double-classified.
- Artifact: `disassembler/coverage_report.json`, regenerated by the test fixture.
- Test: `tests/test_byte_accounting.py` (7 tests) asserts no double-classification,
  full partition coverage, per-region sums, and that unknown bytes are enumerated.
- Full suite: 507 passed.
